# 🚀 AFK Manager X

**AFK Manager X** ist ein automatisierter AFK-Manager für Euro Truck Simulator 2 und die dazugehörigen Multiplayer-Plattformen.

Die Anwendung sendet automatisch eine selbst festgelegte Nachricht in den Spielchat, und das in einem individuell einstellbaren Zeitintervall. So musst du deine Nachrichten nicht mehr manuell schreiben.

## 🎮 Unterstützte Spiele und Plattformen

Aktuell unterstützt AFK Manager X:

- 🚛 Euro Truck Simulator 2 (ETS2)
- 🚚 TruckersMP
- 🚚 HaulMP

**Hinweis:** Derzeit ist AFK Manager X ausschließlich für diese Spiele und Plattformen ausgelegt.

## ⚙️ Funktionen

- 💬 **Automatische Chat-Nachrichten:** Sendet selbstständig Nachrichten in den Spielchat.
- ✏️ **Individueller Nachrichtentext:** Du bestimmst selbst, welcher Text gesendet werden soll.
- ⏱️ **Frei einstellbares Intervall:** Lege selbst fest, alle wie viele Minuten eine Nachricht gesendet wird.
- 🔄 **Automatisierung:** Nach der Einrichtung läuft der Versand automatisch.

## 📌 Aktueller Entwicklungsstand

AFK Manager X befindet sich in aktiver Entwicklung.

Aktuell werden ausschließlich folgende Plattformen unterstützt:
- Euro Truck Simulator 2

## 🚀 Ziel des Projekts

Das Ziel von AFK Manager X ist es, die wiederkehrende Eingabe von Chat-Nachrichten zu automatisieren und dem Nutzer eine einfache Möglichkeit zu bieten, Nachrichtentext und Sendeintervall individuell festzulegen.
